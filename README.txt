MAKIMA XATSPACE // STARTER V1

CARPETAS
assets/makima/  -> makima.png (render principal)
assets/video/   -> intro.mp4 (video de entrada)
assets/music/   -> music.mp3 (música)
assets/gallery/ -> 01.jpg ... 10.jpg (galería)
assets/fonts/   -> fuentes locales opcionales
assets/icons/   -> iconos opcionales

GALERÍA
Edita GALLERY_ITEMS dentro de script.js.
Puedes añadir 10, 20, 50 o más imágenes sin tocar el HTML.
Ejemplo:
{image:'assets/gallery/11.jpg',title:'NOMBRE',description:'Tu frase'}

El diseño no usa scroll y las ventanas se abren/cierra con X.
La música comienza al pulsar ENTER.
